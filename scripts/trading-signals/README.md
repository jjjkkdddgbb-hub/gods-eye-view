# لوحة عين السوق — إشارات تعليمية محلية

صفحة عربية مستقلة لتحليل شموع OHLC محلياً باستخدام مجموعة قواعد توضيحية تجمع RSI(14)، زخم EMA(12/26)، كسر مستوى قريب ثم إعادة اختباره، وسياق Order Block مبسط. لا تعتمد على إطار عمل أو مكتبات أو اتصال خارجي.

## التشغيل

افتح `index.html` في متصفح حديث، أو قدّم مجلد المشروع عبر خادم ملفات محلي. ستظهر بيانات صناعية توضيحية تلقائياً، وموسومة بوضوح بأنها ليست أسعاراً حقيقية. يمكنك أيضاً تحديث الرموز مباشرة من Binance عبر واجهة "تحديث مباشر" باستخدام مفتاح قراءة عام فقط، دون أي حساب أو اعتماد على API خاص.

### تحديث مباشر من Binance (قراءة فقط)

تستخدم الصفحة اتصالاً عامّاً إلى Binance REST API:

```text
https://api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=15m&limit=220
```

هذا اتصال قراءة فقط، لا يطلب حساباً ولا يرسل أوامر تداول. فقط يتم جلب الشموع المفتوحة والعالية والمنخفضة والمغلقة، ثم تحليلها محلياً داخل المتصفح.

### ملف CSV

صيغة CSV: صف عناوين ثم الأعمدة المطلوبة `time,open,high,low,close`، وعمود `volume` اختياري. يقبل الوقت أيضاً باسم `timestamp` أو `date` أو `datetime`، ويقبل OHLC اختصارات `o,h,l,c`. الفاصل فاصلة أو فاصلة منقوطة. يلزم 15 صف شموع صحيح على الأقل. مثال:

```csv
time,open,high,low,close,volume
2025-01-01T00:00:00Z,1.0800,1.0820,1.0790,1.0815,120
```

## حدود مهمة

- لا يوجد تسجيل دخول أو API أو WebSocket أو استخراج بيانات من منصة تداول.
- لا يوجد تنفيذ آلي أو يدوي للصفقات من داخل الصفحة.
- الإشارة ليست توصية استثمارية ولا تتنبأ بالربح. قواعد Order Block والكسر وإعادة الاختبار هنا تقريبية وتعليمية؛ اختبرها على بيانات تاريخية مناسبة ولا تعتمد عليها لاتخاذ قرار مالي.
- تنبيهات المتصفح اختيارية وتصدر بعد ضغط المستخدم على «تحليل الآن» فقط، ولا تعمل في الخلفية.
- يحفظ سجل النتائج في `localStorage` على الجهاز نفسه، ويمكن مسحه من الواجهة.
